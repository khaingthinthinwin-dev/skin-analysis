## 1. 機能概要

### 1.1 目的と範囲

本画面は、コスメティックファインダー向けの完全なお気に入りおよびショッピングカート機能を提供します。お気に入りサブシステムは、認証済みユーザーが将来の参考として商品を保存できるようにし、カートサブシステムは商品選択からチェックアウト開始までの購入ワークフロー全体を管理します。

これらのサブシステムは、商品閲覧と注文確定を橋渡しするe-commerceワークフローの重要なコンポーネントです。シームレスな商品カuration、数量管理、在庫検証、価格計算を支援し、スムーズな購入体験を提供します。

### 1.2 機能責務

本画面は以下のコア機能領域を担当します：

1. **お気に入り管理** — 認証済みユーザーがお気に入りに商品を追加/削除、保存した商品の詳細表示、カートへの移動が可能。
2. **ショッピングカート管理** — 認証済みユーザーがカートに商品を追加、数量更新、商品削除、リアルタイム小計表示が可能。
3. **在庫検証** — カート追加時の在庫確認、数量更新時の在庫検証。
4. **価格計算** — 各カート商品の単価×数量に基づく小計計算。割引およびクーポンはカートページでは**適用されず**、クーポン入力と割引計算はチェックアウトページで行われる。
5. **お気に入りからカートへ移動** — 保存したお気に入り商品をショッピングカートに直接移動可能。
6. **カート永続化** — ログインユーザーのセッション間でカート内容をデータベース保存により維持。
7. **商品表示** — お気に入りおよびカート表示の両方で、商品画像、商品名、価格、在庫状態を表示。

### 1.3 対象ユーザー

| 属性 | 値 |
|------|-----|
| **主要アクター** | 認証済み購入者 |
| **認証要件** | JWT Bearer Token |
| **データ範囲** | 自分のお気に入り商品、自分のカート商品 |
| **ゲスト動作** | カートは永続化されず、お気に入りは利用不可。ゲストユーザーが「カートに追加」または「お気に入りに追加」をクリックすると、アラートモーダル「カートに商品を追加するにはログインしてください。」が表示される。[ログイン]をクリックするとログインページ(`/login`)に遷移。 |

**プロモーション/割引に関する注意事項：** カートページには割引前小計（単価×数量）のみを表示。クーポンコード入力と割引計算は（`要件定義書_REQUIREMENT_SPEC.md`のルール4.5.1および4.5.2に従い）カートページではなく、チェックアウトページ（`/checkout`）で処理される。この分離により、カートはチェックアウトでの完全な価格内訳前の簡単なレビュー手順として維持される。

**ゲストユーザー動作に関する注意事項：** 未認証（ゲスト）ユーザーはカートに商品を追加できない。ゲストユーザーが「カートに追加」または「カートに移動」をクリックすると、メッセージ「カートに商品を追加するにはログインしてください。」のアラートモーダルが表示される。[ログイン]をクリックするとログインページ（`/login`）に遷移。これにより、BR-CART-001およびBR-CART-010で指定されているとおり、カート機能は認証済みユーザーのみが利用可能となる。

## 3. 状態遷移仕様

### 3.1 お気に入り商品の状態

| 状態 | 説明 | お気に入りに表示 | カートに移動可能 |
|------|------|:----------------:|:----------------:|
| `SAVED` | 商品がお気に入りに保存、在庫あり | ✓ | ✓ |
| `OUT_OF_STOCK` | 商品は保存されたが、現在在庫切れ | ✓ | ✗ |
| `PRODUCT_DELETED` | 保存された商品がプラットフォームから削除 | ✓（通知付き） | ✗ |
| `MOVED_TO_CART` | 商品がカートに転送（オプションで自動削除） | ✗（削除された場合） | — |

### 3.2 カート商品の状態

| 状態 | 説明 | カートに表示 | チェックアウト可能 |
|------|------|:------------:|:-----------------:|
| `ACTIVE` | カートに商品あり、有効な在庫 | ✓ | ✓ |
| `LOW_STOCK` | カートに商品あり、閾値以下の在庫（≤10） | ✓（警告） | ✓ |
| `OUT_OF_STOCK` | カートに商品あり、在庫=0 | ✓（エラー） | ✗ |
| `QUANTITY_EXCEEDED` | 要求数量が利用可能在庫を超過 | ✓（エラー） | ✗ |
| `PRODUCT_DELETED` | カート商品の商品が削除 | ✓（通知付き） | ✗ |

### 3.3 お気に入りの状態遷移

| **処理手順** | 1. JWTトークン検証。2. user_idでカート商品をクエリ。3. productsを結合して詳細を取得（商品名、価格、画像、在庫）。4. 各商品の小計を計算。5. 合計小計を計算。6. 各商品の在庫状態を検証。7. サマリー付きカート商品を返却。 |
| **成功レスポンス** | 200 OK（カート商品とサマリー付き） |
| **事後アクション** | 商品とサマリーパネル付きカート表示をレンダリング |

## 9. エラー処理仕様

### 9.1 エラーレスポンス構造

```json
{
  "statusCode": 400,
  "message": ["productId must be a valid CUID"],
  "error": "Bad Request",
  "timestamp": "2026-08-05T12:00:00.000Z",
  "path": "/api/v1/wishlist/abc123"
}
```

### 9.2 エラー分類表 — お気に入り

| HTTPステータス | エラーコード | シナリオ | ユーザー向け動作 |
|---------------|------------|----------|----------------|
| `400` | `BAD_REQUEST` | バリデーション失敗（無効なproductId） | インラインフィールドエラー+トースト |
| `401` | `UNAUTHORIZED` | JWTトークンの欠落または無効 | ログインにリダイレクト |
| `404` | `NOT_FOUND` | 商品が見つからない | トースト：「商品が見つかりません」 |
| `409` | `CONFLICT` | 商品が既にお気に入りにある | トースト：「お気に入りに既に追加されています」 |
| `500` | `INTERNAL_SERVER_ERROR` | サーバーエラー | トースト：「エラーが発生しました。もう一度お試しください。」 |

### 9.3 エラー分類表 — カート

| HTTPステータス | エラーコード | シナリオ | ユーザー向け動作 |
|---------------|------------|----------|----------------|
| `400` | `BAD_REQUEST` | バリデーション失敗（無効な数量） | インラインフィールドエラー+トースト |
| `400` | `BAD_REQUEST` | 在庫切れ | トースト：「商品は在庫切れです」 |
| `400` | `BAD_REQUEST` | 数量が在庫を超過 | トースト：「在庫が{n}個しかありません」 |
| `401` | `UNAUTHORIZED` | JWTトークンの欠落または無効 | ログインにリダイレクト |
| `404` | `NOT_FOUND` | カート商品が見つからない | トースト：「カートに商品が見つかりません」 |
| `404` | `NOT_FOUND` | 商品が見つからない | トースト：「商品が見つかりません」 |
| `500` | `INTERNAL_SERVER_ERROR` | サーバーエラー | トースト：「エラーが発生しました。もう一度お試しください。」 |

### 9.4 フロントエンドエラー表示動作

- **フィールドレベルバリデーション**：無効な入力に赤いボーダーとインラインテキストを表示。
- **トースト通知**：APIエラーおよび成功アクション（追加、削除、更新）に使用。
- **楽観的UI更新**：ハートアイコンはクリック時に即座にトグル。API失敗時にロールバック。
- **読み込み状態**：API呼び出し中のボタンにスピナー。ページコンテンツにはスケルトンローダー。
- **在庫警告**：在庫が少ないまたはゼロのカート商品にインラインバッジ/アラートを表示。
