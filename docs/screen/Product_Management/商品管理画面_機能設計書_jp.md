## 1. 機能概要

### 1.1 目的と範囲

本サブシステムは、Cosmetics Finderマーケットプレイス内のスキンケア商品のライフサイクル全体を管理します。メルカントに商品一覧のCRUD機能、在庫管理、画像アップロードを提供します。

商品管理サブシステムはマーケットプレイスプラットフォームの中心であり、メルカントが商品カタログ、在庫、商品情報を効率的に管理できるようにします。

### 1.2 機能責任

本サブシステムは以下のコア機能領域を担当します：

1. **商品作成** — メルカントは商品名、説明、価格、カテゴリ、画像、肌タイプ適合性、成分、タグを含む新しい商品一覧を作成できます。
2. **商品編集** — メルカントは既存の商品詳細、画像、価格、メタデータを更新できます。
3. **商品削除** — メルカントはソフト削除（`is_active = false`を設定）を行い、検索から非表示にしつつデータを保持できます。
4. **画像管理** — メルカントは商品画像のアップロード、並べ替え、削除ができます（最大10画像、各5MB、JPG/PNG/WebP）。
5. **在庫管理** — メルカントは在庫数の確認と更新、低在庫しきい値の設定、低在庫警告の受信ができます。
6. **おすすめ商品** — メルカントは商品をおすすめとして設定でき、おすすめ商品はホームページに表示されます。
7. **有効/無効トグル** — メルカントは削除せずに商品の表示を切り替えられます。

### 1.3 対象ユーザー

| 属性 | 値 |
|------|-----|
| **プライマリアクター（メルカント）** | 認証済みメルカント（商品カタログを管理） |
| **プライマリアクター（管理者）** | 商品管理フルアクセスを持つ管理者 |
| **必須認証** | メルカント操作にはJWT Bearer Token |
| **データスコープ** | メルカント：自商品のみ。管理者：全商品 |

## 4. ビジネスルール

### 4.1 商品作成ルール

| ルールID | ルール名 | 説明 | 適用層 |
|---------|---------|------|--------|
| BR-PROD-001 | 必須フィールド | 商品には：名前、categoryId、価格、説明が必要 | バックエンド（DTOバリデーション）＋フロントエンド（Zodスキーマ） |
| BR-PROD-002 | 価格正数 | 価格は0より大きくなければならない | バックエンド（DB制約`chk_products_price`） |
| BR-PROD-003 | 比較価格 | compareAtPriceは価格より大きくなければならない（設定時） | バックエンド（DTOバリデーション） |
| BR-PROD-004 | SKU一意性 | SKUは全商品で一意でなければならない（設定時） | バックエンド（DB制約`uq_products_sku`） |
| BR-PROD-005 | スラグ生成 | スラグは商品名から自動生成され、一意でなければならない | バックエンド（スラグユーティリティ） |
| BR-PROD-006 | カテゴリ存在性 | カテゴリは存在し、有効でなければならない | バックエンド（DB FK制約） |
| BR-PROD-007 | デフォルトステータス | 新規商品はデフォルトで`is_active = true` | バックエンド（DBデフォルト） |
| BR-PROD-008 | デフォルトおすすめ | 新規商品はデフォルトで`is_featured = false` | バックエンド（DBデフォルト） |

### 4.2 商品画像ルール

| ルールID | ルール名 | 説明 | 適用層 |
|---------|---------|------|--------|
| BR-PROD-009 | 最大画像数 | 商品あたり最大10枚 | バックエンド（DTOバリデーション） |
| BR-PROD-010 | ファイルサイズ | 画像1枚あたり最大5MB | バックエンド（ファイルアップロードバリデーション） |
| BR-PROD-011 | ファイルタイプ | 許可：JPG、PNG、WebP | バックエンド（MIMEタイプバリデーション） |

### 4.3 商品ステータスルール

| ルールID | ルール名 | 説明 | 適用層 |

### 4.4 在庫ルール

| ルールID | ルール名 | 説明 | 適用層 |
|---------|---------|------|--------|

## 5. 画面仕様

### 5.1 画面：メルカント商品一覧（`/merchant/products`）

**目的：** メルカントが商品カタログを確認・管理できるようにする。

#### 5.1.1 UI要素

**アクションバー：**

| 要素ID | 要素名 | 要素タイプ | i18nキー | 必須 | 説明 |

## 6. 機能操作仕様

### 6.1 操作：商品作成（メルカント）

| 属性 | 仕様 |
|------|------|
| **トリガー** | `/merchant/products/new`で商品フォームを送信 |
| **APIエンドポイント** | `POST /api/v1/products` |
| **リクエストContent-Type** | `multipart/form-data`（画像用）または`application/json` |
| **送信前バリデーション** | 完全なDTOバリデーション（class-validator） |
| **処理ステップ** | 1. JWTトークンとメルカントロールを検証。2. メルカントが承認済みショップを持つことを確認。3. 全必須フィールドを検証。4. 商品名からスラグを生成。5. スラグの一意性を確認。6. 画像をアップロード（提供時）。7. DBに商品レコードを作成。8. 商品リストキャッシュを無効化。9. 作成した商品DTOを返却。 |
| **成功レスポンス** | 201 Created（商品データ付き） |
| **後処理** | メルカント商品一覧にリダイレクト |

### 6.2 操作：商品更新（メルカント）

| 属性 | 仕様 |
|------|------|
| **トリガー** | `/merchant/products/:id/edit`で商品フォームを送信 |
| **APIエンドポイント** | `PATCH /api/v1/products/:id` |
| **リクエストContent-Type** | `multipart/form-data`または`application/json` |
| **送信前バリデーション** | 完全なDTOバリデーション、商品所有権チェック |
| **処理ステップ** | 1. JWTトークンとメルカントロールを検証。2. 商品がメルカントに所属することを確認。3. 全フィールドを検証。4. 商品レコードを更新。5. 画像の追加/削除を処理。6. 商品キャッシュとリストキャッシュを無効化。7. 更新した商品DTOを返却。 |
| **成功レスポンス** | 200 OK（更新した商品データ付き） |
| **後処理** | 編集ページにとどまるか、一覧にリダイレクト |

### 6.3 操作：商品削除（ソフト削除）（メルカント）

| 属性 | 仕様 |
|------|------|
| **トリガー** | メルカント商品一覧で削除ボタンをクリック |
| **APIエンドポイント** | `DELETE /api/v1/products/:id` |
| **リクエストContent-Type** | なし |
| **送信前バリデーション** | 商品所有権チェック |
| **処理ステップ** | 1. JWTトークンとメルカントロールを検証。2. 商品がメルカントに所属することを確認。3. `is_active = false`を設定（ソフト削除）。4. 商品キャッシュとリストキャッシュを無効化。5. 204 No Contentを返却。 |
| **成功レスポンス** | 204 No Content |
| **後処理** | リスト表示から商品を削除、成功トーストを表示 |

### 6.4 操作：在庫更新（メルカント）

| 属性 | 仕様 |
|------|------|
| **トリガー** | メルカント商品一覧または編集フォームで在庫数を更新 |
| **APIエンドポイント** | `PATCH /api/v1/products/:id/stock` |
| **リクエストContent-Type** | `application/json` |
| **送信前バリデーション** | 在庫数≥0、商品所有権 |

| **成功レスポンス** | 200 OK（在庫データおよび該当する場合の低在庫警告付き） |

### 6.5 操作：商品有効/無効トグル（メルカント）

| `admin` | ✓ | ✓ | ✓ | ✓ |

### 10.4 所有権強制

```typescript
// バックエンド所有権チェック例
const product = await this.prisma.product.findUnique({ where: { id } });
if (!product) throw new NotFoundException('Product not found');
if (user.role === 'merchant' && product.merchantId !== user.id) {
  throw new ForbiddenException('You can only manage your own products');
}
```

## 13. 非機能要件

### 13.1 パフォーマンス要件

| 指標 | 目標値 |
|------|--------|
| 画像アップロード（5MB） | ≤ 3秒 |
| 商品作成API | ≤ 1秒 |
| 商品更新API | ≤ 500ミリ秒 |

### 13.2 キャッシュ戦略

| キャッシュキー | TTL | 無効化トリガー |
|---------------|-----|---------------|
| `cache:product:{slug}` | 5分 | 商品更新/削除 |
| `cache:products:list:{hash}` | 2分 | 商品変更時 |

### 13.3 画像最適化

| 要件 | 説明 |
|------|------|
| サムネイル生成 | 100x100、300x300、600x600バリアントを生成 |
| フォーマット | サポート時はWebPで配信、フォールバックでJPEG |
| CDN対応 | 本番環境向けにCDN互換の画像URL |

### 13.4 レスポンシブデザイン要件

| ブレークポイント | レイアウト |
|-----------------|-----------|
| デスクトップ（≥ 1024px） | フルワイド商品フォーム、サイドバーナビゲーション |
| タブレット（768px〜1023px） | フルワイド商品フォーム、折りたたみサイドバー |
| モバイル（< 768px） | スタックフォームレイアウト、ボトムナビゲーション |

### 13.5 アクセシビリティ要件

| 要件 | 実装 |
|------|------|
| WCAG 2.1 AA | セマンティックHTML、全インタラクティブ要素にARIAラベル |
| キーボードナビゲーション | フォームフィールド、ボタン、スイッチを通じたタブ順序 |
| スクリーンリーダー | 商品画像のaltテキスト、アクションのARIAラベル |
| カラーコントラスト | テキスト：最低4.5:1、UIコンポーネント：3:1 |
| フォーカスインジケータ | 全インタラクティブ要素に可见なフォーカスリング |

## 14. 設定可能項目（外部定義）

`.env`設定で定義：

| 定義キー | デフォルト値 | 説明 |
|---------|------------|------|
| `PRODUCT_IMAGES_MAX` | `10` | 商品あたり最大画像数 |
| `PRODUCT_IMAGE_MAX_SIZE_MB` | `5` | 画像1枚あたり最大ファイルサイズ（MB） |
| `PRODUCT_LOW_STOCK_THRESHOLD` | `10` | デフォルト低在庫警告しきい値 |
| `PRODUCT_CACHE_TTL_SECONDS` | `300` | 商品詳細キャッシュTTL（5分） |
| `PRODUCT_LIST_CACHE_TTL_SECONDS` | `120` | 商品リストキャッシュTTL（2分） |
