## 2. 画面概要・目的

### 2.1 目的
商品管理画面は、メルチャントがフルCRUD操作により商品カタログを管理できるようにする。メルチャントは商品の作成、編集、削除、在庫管理、商品画像のアップロード、商品の表示/ステータスの切り替えが可能。管理者ユーザーは全商品にフルアクセス可能。

### 2.2 対象ユーザーと権限

| 属性 | 値 |
| :--- | :--- |
| **主たるアクター** | 認証済みメルチャント（自商品）、管理者（全商品） |
| **認証要件** | JWT Bearer Token |
| **データスコープ** | メルチャント：自商品のみ。管理者：全商品。 |
| **アクセス制御** | 保護ルート — JwtAuthGuard + RolesGuard（merchant/admin） |

### 2.3 主要機能・基本設計方針
1. **商品一覧** — 検索/フィルタ付きでメルチャントの商品カタログを表示・管理。
2. **商品作成** — 詳細情報と画像を含む新規商品リストを作成。
3. **商品編集** — 既存の商品詳細、価格、メタデータを更新。
4. **商品削除** — ソフト削除（`is_active = false`設定）。
5. **画像管理** — 商品画像のアップロード、並べ替え、削除（最大10枚、各5MB）。
6. **在庫管理** — 在庫数量の表示・更新、低在庫警告。
7. **ステータス切り替え** — 商品の有効/無効およびおすすめステータスの切り替え。
8. **国際化** — EN、JA、MYの完全i18n対応。
9. **レスポンシブデザイン** — モバイルファーストのアダプティブレイアウト。

## 5. 各項目における挙動・イベント仕様

### 5.1 商品検索（`txtSearch` onChange）
- **トリガー：** ユーザーが検索入力に文字を入力（デバウンス300ms）。
- **処理ロジック：**
  1. **クライアント側事前チェック：** 入力長≤100を検証。
  2. **バックエンドディスパッチ：** `GET /api/v1/products?search={query}&status={status}`。
  3. **バックエンド実行：** 商品名/SKUにクエリ文字列を含む商品をフィルタ。
  4. **実行後UI：** フィルタ結果で商品テーブルを更新。ページネーションをページ1にリセット。
- **例外処理：**
  - ネットワークエラー：トーストに「検索に失敗しました。もう一度お試しください」を表示。

- **処理ロジック：**
  1. **バックエンドディスパッチ：** `GET /api/v1/products?status={status}`。
  2. **バックエンド実行：** `is_active`ステータスで商品をフィルタ。
  3. **実行後UI：** フィルタ結果で商品テーブルを更新。ページネーションをページ1にリセット。
- **例外処理：** 該当なし。

### 5.8 商品フォーム送信（`btnSave` onClick）
- **トリガー：** ユーザーが「商品を保存」/「商品を更新」ボタンをクリック。
- **処理ロジック：**
  1. **クライアント側事前チェック：** 完全なZodスキーマバリデーション — 必須フィールド全て有効、価格 > 0、画像アップロード済み。

  3. **バックエンド実行：** DTOを検証。スラグを生成。画像をアップロード。商品レコードを作成/更新。キャッシュを無効化。
  4. **実行後UI：** 成功トーストを表示。`/merchant/products`にナビゲート。
- **例外処理：**
  - `VAL_001`（400）：フィールド固有のバリデーションエラーをインライン表示。
  - `409`：「この名前/SKUの商品は既に存在します」を対象フィールドに表示。
  - `413`：「画像ファイルは5MBを超えてはいけません」を表示。
  - `415`：「JPG、PNG、WebP画像のみサポートされています」を表示。
  - ネットワークエラー：「ネットワークエラー。接続を確認してください」を表示。

  4. **`pending`の場合：**
     - `bannerPending`（承認待ちバナー）をページ上部に表示。
     - 全CRUDボタンを非表示：`btnAddProduct`、`btnDeleteAll`、`btnEdit`、`btnDelete`、`swtActive`、`swtFeatured`。
     - 一括アクションアイテムを非表示：`chkSelectAll`、`btnBulkActions`、`btnBulkActivate`、`btnBulkDeactivate`、`btnBulkDelete`。
     - 機能する項目：`txtSearch`、`selStatusFilter`、ページネーションコントロール。
     - 商品テーブルは閲覧専用モードで表示（データ表示、アクションボタンなし）。
  5. **`approved`の場合：** フルアクセス（デフォルト動作）。
- **例外処理：**
  - `401`：ログインにリダイレクト。
  - `403`：権限エラーを表示。

## 11. 特記事項・UI仕様

- **デザインシステム：** ラグジュアリーコスメティックテーマ — プライマリ`#7C3AED`（紫）、アクセント`#EC4899`（ピンク）、セカンダリ`#F3E8FF`（ラベンダー）。
- **レスポンシブビューポートデザイン：** 全ブレークポイントで全幅フォーム。モバイルではテーブルが横スクロール。
- **アクセシビリティ：** 全コントロールはキーボードナビゲーション可能。ARIAラベル必須。エラーメッセージは`role="alert"`で通知。
- **パフォーマンス：** 商品一覧は初期読み込み時にスケルトンローダーを使用。画像アップロードはプログレスバーを表示。ボタンは非同期操作中にスピナーを表示。
- **セキュリティ：** 全ユーザ入力はXSS防止のためサニタイズ。ファイルアップロードはサーバー側で検証（MIMEタイプ + マジックバイト）。クライアント側バリデーションのみを信頼しない。
- **デザイントークン：** ステータスバッジは標準カラーマッピングを使用 — 成功：`bg-green-100 text-green-800`、エラー：`bg-red-100 text-red-800`、警告：`bg-amber-100 text-amber-800`、おすすめ：`bg-yellow-100 text-yellow-800`。
