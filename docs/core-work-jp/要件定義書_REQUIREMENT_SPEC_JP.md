## 1. プロジェクト概要

### 1.1 プロジェクト名
**Cosmetics Finder**

### 1.2 目的
AI搭載のスキンケアマーケットプレイス。ユーザーの肌状態を分析し、パーソナライズされた商品をレコメンドし、購入者と出品者をつなぐ。

### 1.3 主な機能
- AI肌分析とパーソナライズされた商品レコメンド
- スキンケア商品のマルチベンダーマーケットプレイス
- 完全なeコマースワークフロー（閲覧 → カート → チェックアウト → 注文）
- 商品と広告管理のための出品者ツール
- プラットフォーム管理のための管理者パネル
- 多言語対応（英語、ミャンマー語、日本語）

### 2.4 出品者承認ステート

| ステート | 可能な操作 | 不可能な操作 |

## 3. 購入者機能

| 機能 | 説明 |
|------|------|
| 写真アップロード | 顔画像をアップロード（JPG, PNG, WebP、最大10MB） |

| レコメンドの閲覧 | マッチスコア付きのパーソナライズされた商品レコメンド |

| レコメンドのフィードバック | レコメンドを役に立つ/役に立たないと評価 |

#### 分析フロー
```
写真アップロード → AI分析 → 結果閲覧 → レコメンド取得 → 履歴に保存
```

### 5.7 収益と手数料

| 機能 | 説明 |
|------|------|
| プラットフォーム売上 | 総収益、注文数、広告料 |
| 収益ダッシュボード | プラットフォーム収益のトレンド |

| 広告料 | 出品者の広告購入による広告料 |
| 広告料管理 | 管理者が配置場所とティアごとに広告料率を設定/更新可能 |
| 支払い | 出品者への支払い処理（手数料控除後） |
| 収益目標 | 月次/四半期目標の設定と追跡 |

#### プラットフォーム収益概要

| 収益源 | 計算方法 | 例 |
|--------|----------|-----|
| **手数料** | 各売上の設定可能%（デフォルト12%） | $1000 × 12% = **$120** |
| **広告料** | 日額 × 日数 | $5 × 7 = $35 |
| **プラットフォーム総収益** | 手数料 + 広告料 | $120 + $35 = **$155** |

#### 手数料計算
```
手数料 = 注文合計 × 手数料率

デフォルト率：12%（管理者が調整可能）

例：
- 注文合計：$100.00
- 手数料率：12%（設定可能）
- 手数料：$100.00 × 0.12 = $12.00
- 出品者への支払い：$88.00
```

#### デフォルト広告料設定

| 配置場所 | 表示場所 | Basic | Standard | Premium |
|----------|----------|-------|----------|---------|
| ホームページバナー | ホームページ上部 | $3.00/日 | $5.00/日 | $8.00/日 |
| 商品詳細サイドバー | 商品詳細ページ横 | $2.00/日 | $3.50/日 | $6.00/日 |
| カテゴリバナー | カテゴリページ上部 | $2.50/日 | $4.00/日 | $7.00/日 |
| 検索結果上部 | 検索結果の上 | $1.50/日 | $2.50/日 | $5.00/日 |

#### 広告料計算式
```
合計料金 = 日額 × 日数

日額は配置場所とティアごとに管理者が設定可能。

例：
- 配置場所：ホームページバナー
- ティア：Standard
- 期間：7日
- 計算：$5.00 × 7 = $35.00
```

#### 出品者支払い計算
```
純支払い = 総売上 - 手数料

例：
- 総売上：$1,000.00
- 手数料（12%）：-$120.00
- 純支払い：$880.00
```

| 出品者却下 | 管理者が却下 | 出品者 |
| 新規注文 | 購入者が注文 | 出品者 |
| 広告承認 | 管理者が広告を承認 | 出品者 |
| 広告却下 | 管理者が広告を却下 | 出品者 |
| 在庫少 | 在庫が閾値を下回る | 出品者 |
| レビュー報告 | 購入者がレビューを報告 | 管理者、出品者 |
| 新規出品者登録 | 出品者が登録 | 管理者 |
| 新規広告 | 出品者が広告を送信 | 管理者 |
| パスワードリセット要求 | ユーザーがパスワードリセットを要求 | ユーザー（メール経由） |
| パスワードリセット完了 | ユーザーがパスワードをリセット成功 | ユーザー（メール経由） |

### 6.3 パスワードリセット（パスワード忘れ）

| 機能 | 説明 |
|------|------|
| パスワードリセット要求 | 登録済みメールアドレスを入力してリセットリンクを受信 |
| リセットメール送信 | システムがパスワードリセットリンクをメールで送信 |
| リセットリンク有効期限 | リセットリンクは24時間有効 |
| パスワードリセット | ユーザーがリンクをクリックして新しいパスワードを入力 |
| パスワード検証 | 最低8文字必要 |
| レート制限 | メールごとに1時間あたり最大3回のリセット要求 |

#### パスワードリセットフロー
```
メール入力 → リセットリンク受信 → リンククリック → 新しいパスワード入力 → 確認 → ログイン
```

### 6.4 注文インサイト（共通）

すべてのロールは自分のデータのみ閲覧可能：
- **購入者**：自分の注文履歴と追跡
- **出品者**：自店舗の注文のみ
- **管理者**：プラットフォーム全体の注文

## 7. ビジネスルール

### 7.1 認証
- JWTアクセストークン：15分間有効
- リフレッシュトークン：7日間有効、ローテーション付き
- パスワード：最低8文字、Argon2でハッシュ化
- パスワードリセットリンク：24時間有効
- レート制限：メールごとに1時間あたり最大3回のリセット要求

### 7.2 商品
- 有効な商品のみ検索結果に表示
- 在庫は0を下回らない
- 在庫少閾値：10単位（デフォルト）
- 商品ごとに最大10枚の画像

### 7.3 注文
- ステータスフロー：注文 → 確認 → 梱包 → 発送 → 配達中 → 配達完了
- 価格は注文作成時にロック
- 注文時に在庫をアトミックにデクリメント

### 7.4 レビュー
- 認証済み購入者のみレビュー可能
- 商品ごとにユーザー1件のレビュー
- 評価：1〜5スター
- レビューはデフォルトで承認済み、モデレーション可能

### 7.5 プロモーション
- 注文ごとにクーポン1件
- コードは一意であること
- 最大使用回数を超過不可
- 割引は$0を下回らない

### 7.6 広告
- 週あたり最大5件の有効な広告
- 送信前に支払いが必要
- 表示前に管理者の承認が必要
- 却下された広告は再送信可能
- 却下時に返金
- 広告料は配置場所とティアごとに管理者が設定可能

### 7.7 モネタイゼーション
- 各売上のプラットフォーム手数料（管理者設定可能、デフォルト12%）
- 手数料率は注文作成時にロック
- 広告料（配置場所とティアごとに管理者設定可能）- プラットフォーム収益
- 出品者支払い = 総売上 - 手数料

### 7.8 セキュリティ
- バックエンドでロールベースアクセス制御（RBAC）を適用
- すべてのリソースに対する所有権検証
- 重要なアクションの監査ログ記録
- パスワード、トークン、秘密情報を絶対に公開しない
