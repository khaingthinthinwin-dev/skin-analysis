CUID (Collision-resistant Unique Identifier)

  • Time-ordered, globally unique
  • URL-safe, no sequential gaps
  • Perfect for distributed systems

5.3 Cache Invalidation Flow

Write-Through / Evict Strategy
  1. Save changes to PostgreSQL (transaction)
  2. Evict cache key: DEL cache:product:{id}
  3. Invalidate list cache: DEL cache:products:list:*

5.4 Rate Limiting (Sliding Window)

-- sliding_window.lua local key = KEYS[1] local limit = tonumber(ARGV[1]) local window = tonumber(ARGV[2]) local now = tonumber(ARGV[3]) local window_start = now - window redis.call('ZREMRANGEBYSCORE', key, '-inf', window_start) local count = redis.call('ZCARD', key) if count < limit then redis.call('ZADD', key, now, now .. ':' .. math.random(1000000)) redis.call('EXPIRE', key, window) return {1, limit - count - 1} else return {0, 0} end

Prisma Model Definitions

Lookup tables are defined as Prisma models with foreign key references:

  • UserRole model → users.role references user_roles.role_code
  • OrderStatus model → orders.status references order_statuses.status_code
  • DiscountType model → promotions.discount_type references discount_types.type_code
